חלק 3: מילון מונחים וממשק הצב הרשמי

ממשק המשתמש הרשמי של הצב (UNIT4)

🎂 מטפורת העוגה והמתכון

הטיפוס / המחלקה (Class)

המתכון / תבנית האפייה

הגדרת הטיפוס Turtle. המתכון עצמו אינו נאכל ואינו זז על המסך, אך הוא מפרט איזה פעולות ותכונות יש לכל צב.

העצם / המופע (Object)

העוגה האמיתית בזיכרון

העצם שנוצר בפועל עם המילה השמורה new. ניתן ליצור מופעים מרובים (t1, t2), ולכל אחד זיכרון נפרד.

שם הפעולה בממשק פרמטרים תיאור הפעולה הרשמי (UNIT4) דוגמת קוד
Turtle() ללא הפעולה בונה עצם מסוג צב במרכז המסך, פניו מעלה וזנבו מורם. Turtle t1 = new Turtle();
TailDown() ללא הפעולה מורידה את זנב הצב כך שיוכל לצייר. t1.TailDown();
TailUp() ללא הפעולה מרימה את זנב הצב כך שיפסיק לצייר. t1.TailUp();
MoveForward(x) int x הפעולה מזיזה את הצב x צעדים קדימה. t1.MoveForward(100);
MoveBackward(x) int x הפעולה מזיזה את הצב x צעדים אחורה. t1.MoveBackward(50);
TurnLeft(x) int x הפעולה מפנה את הצב x מעלות נגד כיוון השעון. t1.TurnLeft(90);
TurnRight(x) int x הפעולה מפנה את הצב x מעלות עם כיוון השעון. t1.TurnRight(70);
SetTailColor(color) Color color משנה את צבע הקווים שהצב מצייר (מצריך using System.Drawing;). t1.SetTailColor(Color.Red);
SetVisible(b) bool b מציגה את הצב על המסך או מסתירה אותו (false מסתירה). t1.SetVisible(false);
ToString() ללא מחזירה מחרוזת המתארת את מיקום הצב במסך בפורמט <x>,<y>. string p = t1.ToString();
חלק 4: ניתוח שגיאות נפוצות ותפיסות מוטעות

מעבדת איתור באגים (Bug Hunting)

תלמידים מתחילים נופלים לעיתים קרובות במלכודות קלאסיות בתכנות מונחה עצמים. לחצו על הכפתורים מתחת לכל מקרה כדי לקרוא את הסבר השגיאה והפתרון!

מלכודת #1

שכחת המילה new

Turtle t1;
t1.MoveForward(50); // ❌ error!
מלכודת #2

פנייה לטיפוס במקום לעצם

Turtle.MoveForward(50); // ❌ error!
מלכודת #3

שכחת TailDown

Turtle t1 = new Turtle();
t1.MoveForward(100);
// ❓ הצב זז אך לא מצייר קו!
מלכודת #4 (חדש)

פנייה למשתנה Null

Turtle t1 = null;
t1.TailDown(); // ❌ NullReferenceException!
מלכודת #5 (חדש)

דריסת הפניה (Aliasing)

Turtle t1 = new Turtle();
Turtle t2 = new Turtle();
t1 = t2; // ⚠️ שימו לב!
חלק 5: דף עבודה ותרגול מעשי

דף עבודה לתלמיד

1 משימות סרטוט גיאומטרי במעבדה

לפניכם 3 משימות סרטוט קלאסיות. לחצו על "הרצה בסימולטור" כדי לצפות בתוצר החזותי שנוצר על ידי הצב!

משימה 1.1: ריבוע

סרטטו ריבוע שאורך כל צלע שלו הוא 100 צעדים.

t1.TailDown();
t1.MoveForward(100);
t1.TurnRight(90);
// ... x4
משימה 1.2: גרם מדרגות

סרטטו גרם מדרגות בעל 3 מדרגות (גובה 35, רוחב 35).

t1.TailDown();
t1.MoveForward(35);
t1.TurnRight(90);
t1.MoveForward(35);
t1.TurnLeft(90);
משימה 1.3: בית וגג (2 צבים)

צב t1 בונה מלבן אדום, וצב t2 מצייר את הגג המשולש.

t1.SetTailColor(Color.Red);
t2.SetTailColor(Color.Blue);
// עבודה במקביל בזיכרון!

t1.();
