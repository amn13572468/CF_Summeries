לפני שמממשים קוד, ממחישים את מושגי ה-OOP (קימוס, קיבולת, ומצב פנימי) בעזרת שני דליים בעלי קיבולות שונות.

1

הטיפוס (Class Bucket)

מגדיר תכונות: קיבולת מקסימלית (capacity) וכמות מים נוכחית (currentAmount).

2

דלי א' (b1 = 5 ליטר)

נוצר עצם בזיכרון בנפח 5 ליטר. מילוי b1 במים אינו משפיע בשום צורה על דלי b2!

3

מזיגה הדדית (b1.PourInto(b2))

העברת מים בין דליים מקיימת חוקים: דלי יקבל מים רק עד הקיבולת המקסימלית שלו, והשאר יישאר בדלי המקור!

💡 שאלת מחשבה דינמית לכיתה:

יש לנו דלי b1 בנפח 5 ליטר (מלא) ודלי b2 בנפח 3 ליטר (רקוב/ריק). כשאנחנו מבצעים b1.PourInto(b2), כמה מים יישארו ב-b1?

חלק 3: מילון מונחים וממשק המחלקה Bucket

ממשק המחלקה Bucket (UNIT4)

📦 עקרון הקימוס (Encapsulation) בדלי

השדות capacity ו-currentAmount מוגדרים כ-private. אף גורם חיצוני לא יכול לשנות את כמות המים בדלי ישירות, אלא רק דרך הפעולות המורשות בממשק! זה מונע מצב לא חוקי שבו דלי יכיל 10 ליטר מים בעוד הקיבולת שלו היא 5 ליטר בלבד.

שם הפעולה בממשק פרמטרים והחזרה תיאור הפעולה הרשמי דוגמת קוד
Bucket(capacity) int capacity פעולה בונה: יוצרת דלי ריק בקיבולת המבוקשת. Bucket b1 = new Bucket(5);
Fill() ללא (void) ממלאת את הדלי במים עד המקסימום. b1.Fill();
Empty() ללא (void) מרוקנת את הדלי כליל (כמות המים הופכת ל-0). b1.Empty();
AddWater(amount) int amount מוסיפה כמות מים נתונה בדלי (ללא חריגה מהקיבולת). b1.AddWater(2);
PourInto(otherBucket) Bucket other מוזגת מים מהדלי הנוכחי לתוך דלי אחר עד שהשני מתמלא. b1.PourInto(b2);
IsEmpty() מחזיר bool מחזירה true אם הדלי ריק לחלוטין. if (b1.IsEmpty()) ...
IsFull() מחזיר bool מחזירה true אם הדלי מלא עד הקיבולת. if (b1.IsFull()) ...
חלק 4: ניתוח שגיאות נפוצות 🐛

צייד השגיאות (Bug Hunter)

לחץ על השגיאה כדי לצפות בניתוח המלא והתיקון הנדרש בקוד:

שגיאה #1

NullReferenceException בהפעלת דלי

Bucket b1;
b1.Fill();

שגיאה #2

חריגה מקיבולת (Overflow Error)

this.currentAmount += amount; // ללא בדיקה

שגיאה #3

דריסת הפניות ושכפול ערימה (Aliasing Bug)

Bucket b1 = new Bucket(5);
Bucket b2 = b1;

שגיאה #4

גישה ישירה לשדות פרטיים

b1.currentAmount = 10; // Private Violation

חלק 5: דף עבודה ותרגול מעשי 📝

חידת ה-4 ליטרים (תרגיל קלאסי מ-UNIT4)

תיאור המשימה:

נתונים שני דליים: דלי אחד בקיבולת **5 ליטר** ודלי שני בקיבולת **3 ליטר**. עליך לכתוב קטע קוד ב-C# המשתמש אך ורק בממשק המחלקה Bucket כדי להגיע למצב שבו בדלי של 5 הליטרים יש בדיוק **4 ליטר מים**.

פתרון הקוד הנדרש:

Bucket b5 = new Bucket(5);
Bucket b3 = new Bucket(3);

b5.Fill();           // b5: 5, b3: 0
b5.PourInto(b3);     // b5: 2, b3: 3 (מלא)
b3.Empty();          // b5: 2, b3: 0
b5.PourInto(b3);     // b5: 0, b3: 2
b5.Fill();           // b5: 5, b3: 2
b5.PourInto(b3);     // b5: 4, b3: 3 (הגענו ל-4 ליטר ב-b5!)
